# Projeto---Otimiza-o-Inteira-Reprodu-o-do-Artigo-Laporte-et-al.-1992-
Trabalho desenvolvido para a disciplina de Otimização Inteira, com foco na reprodução computacional do artigo "The Vehicle Routing Problem with Stochastic Travel Times", de Laporte, Louveaux e Mercure (1992), por meio da implementação dos modelos P2 e P3 em Python.
